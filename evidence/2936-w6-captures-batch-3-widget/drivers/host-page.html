A third-party site (a plain page on another origin, not the Cinatra app)

This document stands in for the CMS page. It mounts the Cinatra widget in .cw-frame and speaks the embed bridge protocol (cinatra.embed.ready → cinatra.embed.context), exactly as the CMS plugin chrome does. It holds no credential: the frame runs the PKCE sign-in itself, same-origin to Cinatra.
