## Notes

1. Two components draw a Schedule row. A run parked on its scheduling gate without a trigger row uses `RunSurfaceRailRow` with `conformanceId="run-surface-rail-step"` (`instance-screens.tsx:3138–3162`), not `schedule-rail-step`. A selector-based assertion must cover both.
2. `ScheduleRailStep` (`schedule-rail-step.tsx:377–448`) has no production caller (since #3047). It is not graded.
3. L455 says "the rail's first entry is Schedule", while L331 puts both Skills and Schedule ahead of the work steps. With both present, the run page draws Skills first (`instance-screens.tsx:2996–3010`, and the `review-run-surface.tsx:11` comment). This is recorded as a drawing ambiguity (rule 4), and R1 is graded with Skills allowed first.
4. Rule 3: light palette only. No wrong import path in the rail markup.
