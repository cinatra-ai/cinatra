## Notes

1. The panel draws its own rail (StepperColumn) only when the run-surface frame does not (`:3254–3256`). On the ordinary run page the frame draws the rail, and O3 then rests on `run-step-rail.ts`, which both rails consume. O3 and O5 are shared with `run-step-rail-panel` / `run-step-rail-extra-entry`.
2. The ReviewGatePlaceholder keeps a fixed card title and an `aria-label` of "Working on run <ref>" (`review-gate-states.tsx:331–339`). Its own comment argues that this name is not a "status". It is noted, not graded, because the placeholder is not this panel's component, and the departure in O8 stands without it.
3. Rule 4: the failed example draws an "Agentic Run Progress" heading with a status pill, while L443 says the working card names no status. The two readings differ by state (failed vs working), so this is not a contradiction.
4. Rule 3: light palette only. No wrong import path was found in the run-surface markup.
